# Форма / Смысл

**«Сила инфографики и презентаций»** — интерактивное эссе из восьми сцен для семиминутного университетского выступления. Русский интерфейс, авторская векторная графика, локальные эффекты и звук без внешних API. Текст выступления — [MONOLOG.md](MONOLOG.md), научные основания — [SOURCES.md](SOURCES.md).

## Запуск

Нужны Node.js 22.12+ (проверено на 24.22.1) и npm.

```sh
npm ci
npm run dev
```

Сервер слушает порт 5173 и все интерфейсы. В ограниченной облачной среде, если домашний npm-кеш недоступен, используйте `npm ci --cache /workspace/.npm-cache`.

```sh
npm run build
npm run preview
```

Папка `dist/` готова к размещению на обычном статическом хостинге. `base: './'` поддерживает размещение в подпапке. Во время сборки и разработки тексты выступления копируются из корня в `public/`; production-сборка содержит эти документы. Runtime не требует подключения к интернету, CDN, ключей или сервисов. В dev-режиме Vite использует локальный WebSocket для HMR.

## Управление

- Основной маршрут: смысл в круг → коралловый узел сети → правая колонка сквозь потолок → свет на заголовок, диаграмму и центр → одна пара образ/понятие и нить → нулевое начало шкалы и итоговая фраза → четыре понятия → веник.
- **← / →** — предыдущая / следующая сцена с переходом из объектов. Быстрые повторные события блокируются до завершения перехода. Во время захвата объекта переключение запрещено.
- **R** — сброс текущей сцены; **F** — полный экран; **M** — звук; **P** — панель; **пробел** на фоне — пауза.
- Панель выступающего: переход к любой сцене, сброс, пауза, звук и ссылки на речь и источники. Звук изначально выключен; синтезируется Web Audio при разрешённом взаимодействии.
- Сеть: колесо, pinch, перетаскивание фона. При фокусе сети — **+ / −**, стрелки, **0**. Кнопки масштаба дублируют жесты.
- Колонки: захватить и тянуть; при фокусе **↑ / ↓**. Для правой колонки **Enter** или «За пределы» запускает разлом. Минимум каждой доли 8%, максимум 84%; после 70% дополнительное движение усиливает трещину, после максимума меняет только деформацию, а не математические значения.
- Прожектор: перетаскивать световое пятно или нажимать объекты по порядку; с клавиатуры — **Tab, Enter**.
- Образы: перетаскивать к соответствующим целям. Доступная альтернатива — выбрать образ **Enter**, затем понятие **Enter**; повторный Enter на образе также соединяет пару. После одной пары доступна нить перехода.
- Шкала: тянуть коралловый маркер вниз; при фокусе **↑ / ↓**, **Home / End**. Кнопка «К нулю» завершает тот же шаг. Линза перетаскивается; Enter показывает исходные значения и начало шкалы.
- Понятия: провести через все четыре или нажать каждое с клавиатуры.
- Веник: мышь/стилус — захват, касание — удержание 450 мс. **Enter**, затем стрелки — локальная очистка. «Смести следующую полосу» выполняет последовательный проход. При очистке 80% области остаток осыпается. «Повторить финал» восстанавливает маску.

В портретной ориентации сохраняется полный кадр 16:9; для выступления рекомендуется альбомная. Поддерживается `prefers-reduced-motion`. Пауза останавливает GSAP, CSS и Canvas-симуляцию. В данных приложения сохраняются доли, пары, шкала, соединённые понятия, посещённые светом объекты и завершение финала; незаконченные движения и частично очищенная маска пересоздаются при возвращении. Обновление страницы начинает новую сессию.

## Устройство

- `src/App.tsx` — единое состояние, безопасная навигация, GSAP-переходы, Pointer Capture и панель.
- `src/Scenes.tsx` — семь SVG-сцен; D3 zoom, шкалы и кривые.
- `src/Sand.tsx` — маска локальной очистки Canvas и ограниченный пул до 280 смещаемых песчинок. Статическая фактура рисуется один раз. Покрытие считается по сетке области вывода.
- `src/math.mjs` — независимые функции перераспределения и расчёта высот.
- `src/style.css` — адаптивный кадр, палитра и состояния.

## Проверки

```sh
npm test
npm run test:e2e
npm run build
```

Browser-тесты используют системный Chromium `/usr/bin/chromium`. На другой машине задайте `CHROMIUM_PATH=/путь/к/chromium`; либо установите Chromium и его системные зависимости. Playwright сам поднимает dev-сервер, если порт 5173 свободен.

Автоматические проверки: инварианты сумм и минимумов на 10 000 перераспределений; прохождение всех восьми сцен настоящими жестами; пиксельная проверка локальной очистки; возврат назад, сброс, пауза, клавиатура; CDP touch/pinch и удержание веника; уменьшенная анимация, портретный кадр, доступность документов и отсутствие внешних запросов. Скриншоты сохраняются в `test-results/`.

Эмуляция сенсорного экрана в Chromium не заменяет проверку на физическом Android-планшете. Производительность и полноэкранный режим на конкретном устройстве следует проверить перед выступлением. Точное время речи зависит от темпа и интерактивных пауз; репетиция обязательна.

## Публикация на GitHub Pages

Публичный адрес после успешного развёртывания: **https://bublik-you.github.io/GO-GO-DENC/**.

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Затем **Actions → Publish presentation to GitHub Pages → Run workflow → Branch: main → Run workflow**. Если GitHub показывает **I understand my workflows, go ahead and enable them**, сначала нажмите эту кнопку. При ожидании разрешения на развёртывание: **Review deployments → github-pages → Approve and deploy**.

Процесс выполняет сборку, математические тесты, все браузерные проверки на готовой сборке, публикацию и повторные проверки уже по публичному HTTPS-адресу. Смотрите зелёный статус всех трёх заданий: **Build and test all eight scenes**, **Publish HTTPS site**, **Verify the live presentation on desktop and touch**. Отчёты и скриншоты находятся в **Artifacts → live-site-browser-tests** внутри запуска.

Повторная проверка опубликованного сайта из локальной среды:

```sh
PRESENTATION_URL=https://bublik-you.github.io/GO-GO-DENC/ npm run test:e2e
```

С таким параметром Playwright не запускает локальный сервер. Проверки используют относительные пути, поэтому тестируют приложение и документы в подпапке репозитория. В GitHub Actions используется устанавливаемый Chromium Playwright; локально можно указать `CHROMIUM_PATH` или `PLAYWRIGHT_BUNDLED_BROWSER=1` после `npx playwright install chromium`.
